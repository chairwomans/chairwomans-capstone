테스트 이미지의 도메인을 자동으로 파악해 텍스트와 이미지 임베딩을 동적으로 재조합함으로써 도메인 변화에도 정확한 CLIP 기반 Zero-Shot 이미지 분류 연구

Zero-shot Classification Domain Shift Prompt Ensembling
Problem
기존 방식의 한계
기존 CLIP은 텍스트 프롬프트를 평균 내어 클래스 대표 벡터를 고정합니다. 도메인이 달라져도 동일한 벡터로만 비교하기 때문에 Domain Shift 상황에서 이미지-텍스트 정렬이 어긋나 분류 성능이 크게 떨어집니다.

Key Insight
"Sketch이면 sketch template에, photo라면 photo template에 더 높은 weight를."
테스트 이미지 domain 실시간 추정 → 텍스트·이미지 임베딩에 동적 반영 → domain shift에 강건한 zero-shot classification

테스트 단계
1
Image Input & Augmentation
원본 1장에서 RandomCrop 127장 생성, 총 128개의 augmented view 획득. (비용 여유 시 Stable Diffusion 63장 + RandomCrop 64장 생성)
128 views total
2
Visual Encoder
각 view를 ViT에 통과시켜 embedding vector 추출.
ViT
3
MTA — MeanShift
Embedding space에서 밀도 높은 cluster의 mode m* 추출. Outlier 자동 제거해 robust한 image representation 획득.
Outlier auto-removal
4
Domain Assumption
Domain prompt embedding과 m* 간 코사인 유사도 계산 → softmax로 domain weight 산출.
cosine sim + softmax
5
Domain-Weighted Embedding
추정된 domain weight를 텍스트와 이미지에 동일하게 적용 후 각각 dynamic prototype 생성.
Text · Image Embedding
6
Final Classification
Text와 image embedding 간 cosine similarity 비교 → argmax로 최종 class 결정.
argmax cosine similarity
